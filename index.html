Live Google Finance Stock Screener

Paste a ticker list, connect a Google Apps Script web app, and screen live GOOGLEFINANCE data for long-term compounders with positive calendar-year returns.
GitHub Pages front end Google Sheets GOOGLEFINANCE backend No API key Ticker-list based

1. Connect your Apps Script URL

Deploy the backend code shown below as a Google Apps Script web app, then paste the web app URL here.

2. Paste ticker list

One ticker per line. Use exchange prefixes when possible, like NASDAQ:NVDA or NYSE:LLY.

Google Finance does not scan the whole US market automatically. This tool screens only the tickers you paste.

Screener settings

Important limitation

GOOGLEFINANCE does not reliably identify common stock versus ETF, ADR, preferred share, warrant, SPAC, or closed-end fund. Best fix: paste a clean common-stock ticker list from Nasdaq, NYSE, or another source.

This tool uses price return, not dividend-adjusted total return. Some historical returns may differ from professional databases.

Pass rules

3Y, 5Y, 7Y, 8Y, 9Y, and 10Y CAGR must be at least the minimum CAGR.

YTD and 1Y must be positive.

Every completed calendar year in the last 10 years must be positive when strict mode is on.

Data warning

Google Finance data can be delayed, missing, or inconsistent. This is a research tool, not investment advice.
